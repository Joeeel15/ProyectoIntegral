# Proyecto Integral - CampusHub

## Curso
JavaScript Avanzado

## Descripción
CampusHub es un sistema web que permite a los
estudiantes consultar laboratorios y gestionar
reservas de los recursos del campus.

Los administradores pueden gestionar los
laboratorios y visualizar las reservas.

## Tecnologías
- JavaScript
- Node.js
- TypeScript
- Angular
- Bootstrap
- json-server

## Módulos
- core-js
- api-mock
- angular-admin
